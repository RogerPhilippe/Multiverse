Recursos

Um navegador por conta, numa janela só.

O navegador comum guarda um conjunto de cookies por perfil. O Multiverse dá a cada aba a sua própria sessão persistente.

Sessões isoladas

Cookies, armazenamento e cache separados por aba. Uma conta nunca enxerga a outra.

Login que fica

Feche e abra o app: cada conta continua logada. Remover conta… fecha a aba na hora e apaga os dados em segundo plano.

Leve

Só a aba ativa carrega ao abrir. As outras acordam no primeiro clique, com um anel girando enquanto carregam.

Links no lugar certo

Os popups de login abrem dentro do app, na conta certa. Links externos vão para o seu navegador padrão.

Abas filhas

Clique direito → Nova aba filha…: cole uma URL e ela abre já logada na conta. Ideal para o login do Claude Code. Fechar a filha não desconecta a conta.

PIN por conta

A conta com PIN abre bloqueada a cada início do app, e as abas filhas seguem a mesma regra. Remover o PIN pede o PIN atual.

Abas com nome

Duplo clique para renomear: "Trabalho", "Pessoal", "Cliente A". Cada aba tem a sua cor.

macOS, Windows e Linux

Instaladores para Apple Silicon, Windows x64 e Linux x64 (AppImage e .deb).

Claude Code

O Claude Code usa as suas contas, já logadas.

O Multiverse vira um servidor MCP local. Você libera as contas que quiser, e o Claude Code abre páginas, lê, clica, digita e tira prints em abas próprias, em segundo plano, mesmo com o app minimizado.

Você escolhe as contas

Clique direito → Permitir Claude Code. A aba ganha um 🤖, com fundo verde enquanto ele trabalha. Contas bloqueadas por PIN ficam de fora.

Abas dele, não as suas

Na aba da conta ele só lê. Para agir, cria até 5 abas filhas por conta e fecha só as que criou. Downloads, câmera e microfone ficam bloqueados nelas.

Acompanhe ao vivo

Clique na aba 🤖 para ver a página em tempo real e, se precisar, clicar, digitar ou colar nela, por exemplo para resolver um captcha.

Servidor só em 127.0.0.1, com token, desligado por padrão. Passo a passo com prints no manual.
